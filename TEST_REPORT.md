## 7. Critical Vulnerabilities

1.  **DDoS via Unbounded Queries:** Missing pagination schemas in API endpoints allow trivial memory exhaustion. A bad actor with a valid session can deliberately populate thousands of records and repeatedly fetch the root collection endpoints, crashing the specific container.
2.  **Destructive Deletes / Data Loss:** Deletion endpoints physically destroy records instead of masking them via `deletedAt`. Accidental deletions generated by authorized users are irrecoverable without backup restoration.

## 8. Production Blockers

1.  **Implement Pagination:** Introduce `page`/`limit` cursor limits across all `/api/` routing controllers. Update React query queries to handle paginated infinity streams or numbered arrays.
2.  **Overhaul the Deletion Controllers:** Substitute `.delete()` with `.update({ data: { deletedAt: new Date() } })`. Update all controller `findMany` instructions to append `deletedAt: null`.
